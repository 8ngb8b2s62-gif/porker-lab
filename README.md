# POKER LAB — v1.0.2 / 6max Gameplay Update

iPhoneのSafari / GitHub Pagesで動く個人用ポーカートレーニングアプリ。
**MTT・CASHともにPLAYは6maxに統一しました。** この版は「自然なゲーム進行とスマホ画面」を最優先にしています。

## 更新手順（iPhone）
1. `poker-lab-v102-6max.zip` をiPhoneの「ファイル」に保存して展開。
2. GitHubのリポジトリ `porker-lab` のルートを開く。
3. `Add file` → `Upload files` から、展開したフォルダの**中身11ファイル**を選択してアップロード。フォルダごと入れないでください。
4. `Commit changes`。Pages反映後、 https://8ngb8b2s62-gif.github.io/porker-lab/ をSafariで再読み込み。
5. 古い見た目が残る場合はSafariで再読み込み／サイトデータ・サービスワーカーのキャッシュを確認。サイトデータの削除は保存済みプレー履歴も消すため、先にDATAからバックアップしてください。

## 今回の変更
- 6max専用の簡易プリフロップ・レンジ判断。未参加からのオープンリンプをしない。2.2BB MTT / 2.5BB CASH付近のオープン、3betと4betには慎重に応答。
- AIは**約0.6〜0.9秒間隔で1人ずつ**行動。現在のプレイヤーを点灯し、行動の結果を都度画面へ反映。
- 相手のハンドは**2枚の裏向きカード**で表示。ショーダウンで参加者の表カードを表示（フォールド済みは非表示）。
- 6max向けのテーブル位置を採用し、iPhoneの基本PLAY画面は一画面で操作。レイズサイズはボタンから展開。
- 画面上部の情報を簡素化。バージョン・キャッシュを更新。
- 修正版のベット/レイズ表示。1ストリート未ベットの初回ベットはBETと記録。

## 残る制約
- **AIのレンジ・ポストフロップ判断は独自の教材用近似であり、GTOソルバーの計算結果ではありません。** ヨコサワの書籍の表データ自体を転写したものではありません。
- GTO頻度・EV・EV Loss・GTO正答率は未計算。アクション後の理論解説はソルバーによる正解判定ではありません。
- MTTの他卓参加人数は概算。ICM計算機は賞金期待値の計算であってMTTの全局面を解くソルバーではありません。
- レンジライブラリの色は参考分類で、AIのレンジと完全同期するソルバーデータではありません。
- 保存先は各ブラウザのlocalStorageです。端末間同期はありません。
- ローカルのPCブラウザでエンジンと表示を確認していますが、iPhone実機Safari上のタッチ操作までは確認していません。
