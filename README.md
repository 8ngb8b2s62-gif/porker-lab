# POKER LAB v0.4 — interactive prototype

個人学習用、iPhone Safari/GitHub Pages対応。ソルバー検証済みのGTOデータは**未収録**です。

- PLAY: Hero vs Villain のヘッズアップポットをプリフロップからショーダウンまで継続。チェック、コール、フォールド、ベット、レイズ、オールイン（額指定）、ポットとスタックの計算、7枚から5枚の役判定。
- TRAIN: テーマとホールカードを指定した練習。
- RANGES: 13×13マトリクス、ポジション・スタック・アクション条件選択。**色はハンド分類でGTOレンジではない**。
- REVIEW: 全アクションの理論ベースのレビュー、端末内の履歴。
- AI: タイプ別の簡易ルール。適応型AIやGTOソルバーではありません。

## 未実装・制限
9席は表示のみ。複数人ポット、サイドポット、完全なMTT進行、ICM計算、FGS、厳密なベットルールの全例外、ソルバー戦略の取り込み、検証済みEV、相手AIの適応学習は未実装。これは完成版ではなく、機能をつなげるための試作版です。**実戦でのGTO正解として利用しないでください。**

## 更新方法
GitHub Pagesのリポジトリのルートに6ファイルをアップロード。Safariで `?v=4` を付けて再読み込み。GitHub Pagesは公開サイトなので個人情報や非公開レンジデータを置かないこと。
