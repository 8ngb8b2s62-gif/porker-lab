# POKER LAB v0.3

iPhone対応のポーカー学習用PWAです。

- PLAY: MTT / キャッシュそれぞれ2シナリオ。プリフロップからリバーまで連続して判断。9座席表示。
- STUDY: 13×13の簡易オープンレンジ可視化。**ソルバー検証済みのGTOレンジではありません。**
- 成績: 判断数、教材の推奨/代替選択肢との一致率、ストリート別の記録を端末内に保存。

## 注意
シナリオの相手アクション・ポットサイズは教材として事前設定したものです。プレイヤーのベットサイズによる厳密なポット再計算や相手の適応戦略は未実装です。GTO頻度を推測で表示することはしていません。
